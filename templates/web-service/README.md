# Сервис для коллег по ссылке

Эта папка: проект сервиса, который работает в интернете. Коллеги открывают его по ссылке и вводят код доступа.
Делает и меняет сервис Claude: откройте эту папку в новом разговоре (вкладка **Code** → **Local** →
**Open folder…**) и опишите словами, что нужно.

## Что сказать Claude здесь

- «покажи сервис»: страница откроется на этом компьютере, с той же базой, что в интернете;
- «опубликуй сервис»: сервис выйдет в интернет (первый раз) или обновится на сайте (дальше);
- «смени код доступа»: новый код, старый перестанет работать;
- «смени ключ базы»: новый пароль базы для сервиса.

В кабинете на карточке сервиса есть адрес сайта, код доступа («Показать код») и «Показать на компьютере».

## Что где лежит

| Папка или файл | Что это |
|---|---|
| `public/` | страница сервиса (`index.html`), `public/ui/` набор интерфейса кабинета |
| `api/index.py` | действия сервиса: что считает и что отдаёт странице |
| `db/` | таблицы базы по шагам: `001_init.sql`, `002_...sql` |
| `lib/` | помощники кабинета (сервер, база, драйвер): их обновляет кабинет, править не нужно |
| `service.json` | паспорт: название, вид `web`, адрес публикации |
| `.env` | ключи сервиса: только на этом компьютере, в git не уходит |

Персональные данные (ФИО, ИИН, телефоны) в этом сервисе не храним, пока нет письменного согласия юристов
или ИБ. Коммерческие данные можно.
