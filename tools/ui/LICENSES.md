# Лицензии набора интерфейса

Сторонние файлы в этой папке взяты из пакетов npm без изменений. Все три под лицензией MIT: её текст ниже, у каждого пакета свой.

| Файл | Пакет | Версия | Файл в пакете |
|---|---|---|---|
| `basecoat.css` | basecoat-css | 1.1.0 | `dist/basecoat.cdn.min.css` |
| `basecoat.js` | basecoat-css | 1.1.0 | `dist/js/all.min.js` |
| `basecoat-chart.js` | basecoat-css | 1.1.0 | `dist/js/chart.min.js` |
| `chart.js` | chart.js | 4.5.1 | `dist/chart.umd.min.js` |
| `tailwind.js` | @tailwindcss/browser | 4.3.1 | `dist/index.global.js` |

Файлы кабинета `kabinet.css`, `kabinet.js` и `demo.html` написаны для курса.
