# Задача 1. Аналитика продаж по точкам и продавцам

**Тип задачи:** сводная. **Подразделение:** розничная сеть ювелирных изделий.

Каждый понедельник директор смотрит, как прошла неделя по точкам: где упала выручка, какой средний чек, кто из продавцов продаёт больше, какой товар везти на точку. Сейчас это делается по фото продаж в WhatsApp. Сегодня понедельник, 9 ноября 2026 года, и отчёт готовите вы.

**Файл:** `prodazhi_1c.csv`, выгрузка из 1С за 26 октября - 8 ноября.

## Что нужно получить

1. Таблицу: выручка в тенге, число продаж и средний чек по каждой точке за неделю 26 октября - 1 ноября и за неделю 2-8 ноября, изменение в процентах.
2. Точки с самым большим падением выручки.
3. Продажи по продавцам за последнюю неделю: выручка и число продаж.
4. Три-пять предложений выводов для директора.

Таблицу сохраните в Excel.

## Готово, когда

- В таблице 6 точек.
- Каждая цифра в таблице берётся из файла, Claude может показать, из каких строк.
- Если по какой-то точке данные неполные, это написано прямо, без досчитывания.
- Строки без продавца, повторы и возвраты найдены и названы, а не молча посчитаны.
- Выводы опираются на таблицу и не обещают того, чего в данных нет: причин падения в выгрузке нет.

## Со звёздочкой

1. Файл `prodazhi_1c_god.csv` за год. Соберите помесячную динамику выручки по точкам и найдите, в каких месяцах данных не хватает. Файл большой: попросите Claude написать и запустить программу, которая посчитает итог. Не вставляйте файл в чат и не просите Claude прочитать его целиком.
2. Файл `ostatki_1c.xlsx`. Сравните остатки с продажами последней недели: на каких точках каких изделий осталось меньше, чем продано за неделю. Это подсказка, что везти на точку.
3. Файл `shablon_otcheta.docx`. Заполните шаблон отчёта директору цифрами из таблицы. Поле, для которого в данных ничего нет, оставьте с пометкой «[нет данных]», не выдумывайте.
